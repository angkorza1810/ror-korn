# Ror-Korn · สวนสนุกออมเงิน 🎢

เว็บบัญชีรายรับรายจ่ายธีมสวนสนุก ใช้ได้หลายคนผ่านลิงก์เดียว ข้อมูลเก็บใน **Firebase** ทุกคนเห็นข้อมูลชุดเดียวกัน แต่เงินส่วนตัวของแต่ละคนเป็นความลับ

**มีอะไรบ้าง**
- เข้าใช้ด้วย **ID + รหัสผ่าน** (ID เปลี่ยนไม่ได้ / ชื่อเล่น รูป และรหัสผ่านเปลี่ยนได้ในหน้าตั้งค่า)
- **สมัครเอง → รอเจ้าของเว็บ (`angkor`) อนุมัติ** / **สมัครผ่านลิงก์เชิญ → ใช้ได้ทันที**
- หน้า **สมาชิก** สำหรับเจ้าของเว็บ: อนุมัติ / ปฏิเสธ / ระงับ
- เพิ่ม แก้ไข ลบรายการ (ได้เฉพาะของตัวเอง) พร้อมไอคอนที่ขึ้นเองจากชื่อ และอัปโหลดรูปเองได้
- **แชร์ค่าใช้จ่ายกับเพื่อน**: หารเท่ากันหรือกำหนดเอง → ระบบแจ้งเตือนเพื่อน → เพื่อนกดรับ → แจ้งว่าโอนแล้ว → คนจ่ายกดยืนยัน
- **กระดิ่งแจ้งเตือน** ในเว็บ
- **ผลวิเคราะห์** รายสัปดาห์ / รายเดือน
- **เป้าหมาย 3 ระดับ**: ลู่วิ่ง Lv.1 (เพลย์เซฟ) · รถไฟเหาะ Lv.2 (เร็วขึ้น 30%) · ทอร์นาโด Lv.3 (เร็วขึ้น 2 เท่า) โดยยอดที่ต้องเก็บไม่เกิน 60% ของเงินเหลือเฉลี่ย
- พอสำเร็จ จะได้ฉากฉลองพลุ พร้อมรูปอวตารของคุณนั่งบนเครื่องเล่น

> ถ้ายังไม่ตั้งค่า Firebase เว็บจะทำงาน **โหมดทดลอง** (ข้อมูลอยู่ในเบราว์เซอร์เครื่องเดียว) เปิดดูได้ด้วย `python3 -m http.server 8000` แล้วเข้า http://localhost:8000

## ขั้นตอนทั้งหมด (ทำตามลำดับ)

ใช้เวลาประมาณ 15–20 นาที ไม่ต้องผูกบัตรเครดิต (ใช้แพ็กเกจฟรี Spark)

### ขั้นที่ 1 · สร้างโปรเจกต์ Firebase
1. เข้า https://console.firebase.google.com แล้วล็อกอินด้วยบัญชี Google
2. กด **Create a project** (หรือ "เพิ่มโปรเจกต์")
3. ตั้งชื่อ เช่น `ror-korn` → Continue
4. Google Analytics: **ปิด** ได้เลย (ไม่จำเป็น) → **Create project** → รอสักครู่ → Continue

### ขั้นที่ 2 · เพิ่ม Web App แล้วเอา config มาใส่
1. ในหน้าโปรเจกต์ กดไอคอน **`</>`** (Web)
2. ตั้งชื่อแอป เช่น `ror-korn-web` (**ไม่ต้อง**ติ๊ก Firebase Hosting) → **Register app**
3. จะเห็นโค้ดที่มี `const firebaseConfig = { apiKey: ..., authDomain: ..., ... }`
4. คัดลอกค่าทั้ง 6 บรรทัดไปวางในไฟล์ **`config.js`** ตรง `firebaseConfig`

```js
firebaseConfig: {
  apiKey: 'AIzaSy...',
  authDomain: 'ror-korn.firebaseapp.com',
  projectId: 'ror-korn',
  storageBucket: 'ror-korn.firebasestorage.app',
  messagingSenderId: '1234567890',
  appId: '1:1234567890:web:abc123'
},
```
> ค่าพวกนี้เปิดเผยบน GitHub ได้ ไม่ใช่รหัสลับ ความปลอดภัยคุมด้วยกฎในขั้นที่ 4

### ขั้นที่ 3 · เปิดระบบเข้าสู่ระบบ
1. เมนูซ้าย **Build → Authentication** → **Get started**
2. แท็บ **Sign-in method** → เลือก **Email/Password** → เปิด **Enable** (ช่องแรก) → **Save**
   (เว็บแปลง ID เป็นอีเมลภายใน เช่น `mark` → `mark@rorkorn.app` จึงไม่มีการส่งอีเมลจริง)

### ขั้นที่ 4 · สร้างฐานข้อมูล + วางกฎความเป็นส่วนตัว
1. เมนูซ้าย **Build → Firestore Database** → **Create database**
2. Location: เลือก **asia-southeast1 (Singapore)** (เร็วที่สุดสำหรับไทย เปลี่ยนภายหลังไม่ได้)
3. เลือก **Start in production mode** → **Create**
4. ไปที่แท็บ **Rules** → ลบข้อความเดิมทั้งหมด → เปิดไฟล์ **`firestore.rules`** ในโปรเจกต์นี้ คัดลอกทั้งไฟล์มาวาง → **Publish**
   > ถ้าหน้า Rules ขึ้นตัวแดงว่ามี error ให้ถ่ายรูปข้อความส่งมา

### ขั้นที่ 5 · สร้างบัญชีเจ้าของเว็บ `angkor`
บัญชีนี้สร้างในหน้า Console เพื่อไม่ให้ใครแย่งชื่อไปก่อน
1. **Authentication → Users → Add user**
2. Email: **`angkor@rorkorn.app`**
3. Password: รหัสผ่านที่คุณตั้งไว้ (อย่าเขียนรหัสนี้ลงในไฟล์ใดๆ ของโปรเจกต์)
4. **Add user**

ล็อกอินครั้งแรกด้วย ID **`angkor`** แล้วระบบตั้งชื่อเล่น "อังกอร์" และเปิดหน้า **สมาชิก** ให้อัตโนมัติ
> เพื่อความปลอดภัย เมื่อเข้าได้แล้วแนะนำให้เปลี่ยนรหัสผ่านในหน้า ⚙️ ตั้งค่า

### ขั้นที่ 6 · เอาขึ้น GitHub
1. สมัคร/ล็อกอิน https://github.com → กด **+** มุมขวาบน → **New repository**
2. Repository name: `ror-korn` · เลือก **Public** · **ไม่ต้อง**ติ๊กสร้าง README → **Create repository**
3. แตกไฟล์ zip แล้วเปิด Terminal ในโฟลเดอร์ `ror-korn` (ใน zip มี commit ไว้ให้แล้ว)

```bash
cd ror-korn
git add config.js
git commit -m "ใส่ค่า Firebase"
git remote add origin https://github.com/<ชื่อ GitHub ของคุณ>/ror-korn.git
git push -u origin main
```
> ถ้าเครื่องยังไม่มี git ให้ใช้ **GitHub Desktop** (https://desktop.github.com) → File → Add local repository → เลือกโฟลเดอร์ → Publish

4. ที่หน้า repo: **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
5. รอ 1–2 นาที แล้วจะได้ลิงก์ **`https://<ชื่อ GitHub>.github.io/ror-korn/`**

### ขั้นที่ 7 · อนุญาตโดเมน GitHub ใน Firebase (สำคัญ)
1. **Authentication → Settings → Authorized domains → Add domain**
2. ใส่ **`<ชื่อ GitHub>.github.io`** → Add

เสร็จแล้ว เปิดลิงก์จากขั้นที่ 6 แถบเมนูจะขึ้นว่า **FIREBASE · ออนไลน์**

## ใช้งานกับเพื่อน

| อยากทำอะไร | ทำยังไง |
|---|---|
| ให้เพื่อนสมัคร (รออนุมัติ) | ส่งลิงก์เว็บให้เพื่อน → เพื่อนกด "สมัครใหม่" → คุณ (angkor) เปิดเมนู **สมาชิก** → **อนุมัติ** |
| ชวนเข้ากลุ่ม (ใช้ได้ทันที) | เมนู **กระเป๋า** → สร้างกลุ่ม → **คัดลอกลิงก์เชิญ** หรือส่งทาง LINE |
| เพิ่มคนที่มีบัญชีแล้ว | เมนู **กระเป๋า** → ใส่ **ID** เพื่อน → เพิ่ม |
| ให้ใครดูกระเป๋าส่วนตัว | เลือกกระเป๋าส่วนตัว → เมนู **กระเป๋า** → ใส่ ID → เขาดูได้อย่างเดียว |
| หารค่าข้าว | **เพิ่มรายการ** → ติ๊ก **แชร์กับเพื่อน** → ใส่ยอดเต็ม → เลือก **หารเท่ากัน** หรือ **กำหนดเอง** |

## ใครเห็นอะไรได้บ้าง
- **กระเป๋าส่วนตัว:** เห็นแค่เจ้าของ (และคนที่เจ้าของให้สิทธิ์ดู)
- **กลุ่ม:** เห็นเฉพาะสมาชิก ทุกคนแก้และลบได้เฉพาะรายการของตัวเอง
- **รายการแชร์:** เห็นเฉพาะคนที่อยู่ในรายการนั้น
- **คนที่ยังไม่ได้รับอนุมัติ:** มองไม่เห็นข้อมูลอะไรเลย
- **ที่ทุกคนเห็นได้:** ID ชื่อเล่น และรูปโปรไฟล์ (ใช้ค้นหาเพื่อน)

กฎทั้งหมดบังคับในฐานข้อมูล (`firestore.rules`) ไม่ใช่แค่ซ่อนบนหน้าจอ

## เปลี่ยน ID เจ้าของเว็บ
ต้องแก้ 2 ที่ให้ตรงกัน คือ `adminId` ใน `config.js` และ `angkor@rorkorn.app` ใน `firestore.rules` (มี 2 จุด) แล้ว Publish กฎใหม่

## ลืมรหัสผ่าน
ระบบใช้ ID แทนอีเมล จึงส่งลิงก์รีเซ็ตทางอีเมลไม่ได้ ให้เจ้าของเว็บไปที่ Firebase **Authentication → Users** → กด ⋮ ที่บัญชีนั้น → **Reset password**

## โควตาฟรี
แพ็กเกจ Spark อ่านข้อมูลได้ 50,000 ครั้ง และเขียน 20,000 ครั้งต่อวัน เหลือเฟือสำหรับกลุ่มเพื่อน
รูปโปรไฟล์และรูปรายการจะถูกย่อแล้วเก็บใน Firestore จึงไม่ต้องใช้ Cloud Storage ซึ่งต้องผูกบัตร

## โครงไฟล์
```
index.html        หน้าเว็บ
style.css         ธีม (แก้สีได้ที่ตัวแปรใน :root)
config.js         ค่า Firebase + ID เจ้าของเว็บ
firestore.rules   กฎความเป็นส่วนตัว (วางใน Firebase Console)
db.js             เชื่อมฐานข้อมูล (Firebase หรือโหมดทดลอง)
store.js          ตรรกะ: บัญชี อนุมัติ กระเป๋า เป้าหมาย แชร์ แจ้งเตือน
app.js            หน้าจอทั้งหมด
rides.js          เครื่องเล่น + ฉากฉลอง
icons.js          ไอคอนรายการ + คำที่ใช้จับคู่รูป (เพิ่มคำได้ใน KEYWORDS)
avatars.js        อวตาร 16 แบบ
vendor/           Firebase SDK, ฟอนต์ Mitr/Anuphan, ไอคอน Tabler (ไม่ต้องโหลดจากเน็ต)
```

ไลบรารีที่ใช้: Firebase JS SDK (Apache-2.0), Tabler Icons (MIT), Mitr และ Anuphan (SIL OFL)
